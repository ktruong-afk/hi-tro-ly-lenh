# Hi Trợ Lý — gói lệnh (dự phòng)

Repo này **chỉ** chứa phần app Hi Trợ Lý tự tải về để cập nhật, **không có mã nguồn app**:

| File | Dùng làm gì |
|---|---|
| `commands.json` | Gói lệnh giọng nói: câu nói → việc cần làm, kèm nội dung màn "Hướng dẫn" |
| `commands.json.sig` | Chữ ký số của gói lệnh. App chỉ nhận gói có chữ ký đúng, sửa tay file json là app bỏ qua |
| `version.json` | Thông tin bản app mới nhất (app hiện "Có bản mới") |

Nguồn chính: https://hitroly.conggame.online/goi-lenh/ — repo này là đường dự phòng khi web trục trặc.
Tải app: https://hitroly.conggame.online

Cập nhật: chạy `tools\cap-nhat-lenh.bat` (hoặc nút "Ký & đưa lên" ở trang soạn lệnh) trên máy tác giả — tự ký, đưa lên web và đẩy vào repo này.
